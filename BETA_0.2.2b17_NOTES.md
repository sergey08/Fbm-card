# FBM Card 0.2.2b17 (Beta)

## English

The visual editor exposes Search and Fixed Team. Legacy configuration remains usable, and existing card IDs and crest overrides are preserved. The team search gives feedback for empty, loading, failed and no-result states and preserves the active query across editor updates.

## Español

El editor visual ofrece Buscar equipos y Equipo fijo. La configuración anterior sigue siendo compatible y se conservan los identificadores y escudos existentes. La búsqueda avisa si falta el nombre, muestra el progreso, informa si falla o no encuentra equipos y mantiene la consulta al actualizar el editor.
