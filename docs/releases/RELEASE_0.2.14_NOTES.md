# FBM Card v0.2.14

## English

Recent results show the published scores from the latest matchday with results. They use the same fixture layout as Upcoming games, with official crests when available and a centered blue scoreboard.

## Español

Últimos resultados muestra los marcadores publicados de la jornada más reciente con resultados. Utiliza el mismo formato de Próximos partidos, con los escudos oficiales disponibles y el marcador azul centrado.
