# FBM Card v0.2.11 — HACS catalog eligibility

## English

- Prepared FBM Card for submission to the official HACS/Marketplace default catalog as an **integration**.
- Added the MIT license for the project's original source, clearly distinguishing the rights of third-party FBM/Gesdeportiva content, logos, photos, data, and APIs.
- Added HACS Action and Home Assistant Hassfest validation workflows; fixed manifest key ordering.
- Added repository topics and `country: ES` to the HACS metadata because the data concerns competitions in Madrid, Spain.
- No changes to runtime behavior, team settings, saved archives, or Lovelace cards relative to v0.2.10.
- **The repository has not been accepted into the official HACS catalog yet.** Until acceptance, continue installing it as a custom repository.
